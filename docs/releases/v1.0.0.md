# ValTool Stream Overlay v1.0.0 — Windows Release

A customizable VALORANT statistics overlay for OBS, with a local browser editor and Windows tray controls.

## Features

- Automatically connects to your running Riot Client and VALORANT session, with no separate sign-in.
- Shows your current rank, RR, K/D, KDA, ACS, win rate, RR changes, and recent match results.
- Supports the latest N matches or all available competitive history, with an optional current-act filter.
- Includes three overlay sizes, Midnight and Pastel themes, customizable colors and metrics, and preset import/export.
- Shows the number of matches used in statistics on every card size, with an optional ValTool logo and name watermark.
- Improves text readability with larger fonts and stronger contrast, plus selectable 100%/200%/300% native rendering. The recommended default is 200%; the editor displays the exact OBS source dimensions.
- Provides a transparent OBS Browser Source with live updates and a URL that survives app restarts.
- Offers an independent sample-data preview for customization; normal mode uses your real statistics.
- Adds a Windows tray menu to reopen settings, refresh statistics, or quit, plus a ValTool executable icon.
- Saves settings and match history locally and handles Riot request limits without losing completed work.

## Download and launch

1. Download `ValTool-Stream-Overlay-v1.0.0-windows-x64.zip` from this release.
2. Extract the complete archive. Keep `_internal` next to `ValTool Stream Overlay.exe`.
3. Run `ValTool Stream Overlay.exe`. No separate Python or Node.js installation is required.
4. Sign in to Riot Client and launch VALORANT. Settings open in your browser.
5. Copy the OBS URL into an OBS Browser Source and use the dimensions shown in the editor.

When updating from an earlier build, update the Browser Source Width and Height to match the editor, then use Transform → Reset Transform and reposition it. The 200% Compact card is 600 × 268 without recent matches, or 600 × 356 with them. Existing smaller browser viewports fit without cropping, but the full reported size provides the larger native render.

Closing the browser tab keeps the overlay running. Use **Quit app** in the editor or **Quit ValTool Stream Overlay** in the tray menu to exit. Windows may place the tray icon under the hidden-icons arrow.

## Data and upgrades

Settings and the match cache are stored in `%LOCALAPPDATA%/ValTool Stream Overlay/`. Preserve this directory to retain your settings and OBS URL. Close the app before replacing an older build; extract and use the complete new application folder.

The app and OBS must run on the same computer. Riot limits accessible history, so “All” means all available matches rather than a guaranteed lifetime archive. Live data requires access to Riot services. Riot credentials stay in backend memory and are not included in the overlay or local database.
